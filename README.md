# Lab01 — Поведение пользователей и рекламные клики

Лабораторная работа по статистике: анализ датасета рекламных кликов (1000 пользователей), подбор распределений,
оценки и гипотезы, собственные генераторы случайных величин (вихрь Мерсенна MT19937).

Страница отчёта: откройте `index.html` (или GitHub Pages: *Settings → Pages → Deploy from branch → main / root*).
